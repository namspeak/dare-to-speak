# daretospeak.vn/sach/ — Landing page sách S-PEAK!

Trang tĩnh, phục vụ tại `/sach/` (`sach/index.html`).

## Cấu trúc
- `assets/styles.css` — layout & component
- `assets/brand-refresh.css` — màu/nhấn thương hiệu (cam–đỏ–tím–đen)
- `assets/app.js` — popup đặt sách demo, đọc thử, mục lục
- `assets/data/demo-content.js` — **nội dung demo** (mục lục, đoạn đọc thử), cần thay bằng bản tác giả duyệt
- `assets/fonts/fonts.css` — Anton, Barlow Condensed, Plus Jakarta Sans (Google Fonts)
- `assets/images/book-reference.webp` — **bìa tạm** do dựng lại; thay bằng bìa thật (tỉ lệ 5:7)
- `downloads/speak-reading-sample-demo.pdf` — PDF đọc thử demo

## Còn ở chế độ demo
- Form đặt sách chưa gửi dữ liệu, chưa thu tiền
- Trang đang `noindex`, gỡ khi sẵn sàng công khai
